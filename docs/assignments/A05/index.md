## Objective
The objective of this assignment is to determine the dimensions for a bracket by analyzing normal stress, bending stress and stiffness equations and using the strength of the material. Free Body diagrams will be created in order to analyze the different forces on each feature of the bracket. Known and unknown variables, assumptions, and algebraic models will be established in order to come to the conclusion of the correct dimensions for each feature. Perform stiffness analysis to establish a minimum dimension based on the deflection constraints given. Stress and stiffness analyses will be compared in order to make sure both constraints are met. Multiview sketches will be created in order to show what dimensions have been defined for each feature. Key engineering lessons learned throughout this process will also be documented.
